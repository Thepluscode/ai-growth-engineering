# Agents: start at CLAUDE.md

This repository's entrypoint is `CLAUDE.md` — a thin bootstrap that tells any agent,
Claude Code or otherwise, what to read and in what order.

Stable project truth — mission, boundaries, invariants, source-of-truth rules — lives in
`AGENT_CONTEXT.md`. The current authorised task lives in `ACTIVE_WORK.yaml`.

This file used to hold the working agreement. It was moved into `AGENT_CONTEXT.md` on
2026-09-20 so that one document carries the doctrine: two substantive instruction files in
one repository is how they drift apart.
